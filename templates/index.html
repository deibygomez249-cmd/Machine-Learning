What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence that allows computers to learn from data, recognize patterns, and make predictions or decisions without being explicitly programmed for every specific scenario.

For example, it can be used to detect spam emails, recommend products, recognize images, analyze data, or make forecasts.

Types of Machine Learning
Supervised Learning

The system learns using previously labeled data, where the expected output is already known.

Example: Training a system with images identified as "dog" and "cat" so it can classify them later.

Classification & Regression
Unsupervised Learning

The system works with unlabeled data and independently searches for patterns, relationships, or clusters.

Example: Grouping customers based on their purchasing habits.

Clustering & Dimensionality Reduction
Semi-supervised Learning

Combines both previous methods. Uses a small amount of labeled data alongside a larger amount of unlabeled data.

Example: Classifying thousands of images when only a few have been previously identified.

Hybrid Approach
Reinforcement Learning

The system learns through trial and error. Receives rewards when performing actions correctly and penalties when making incorrect decisions.

Example: Training an AI agent to learn how to play a video game.

Linear Regression Application

Explore a practical implementation of Simple Linear Regression using real data to analyze the relationship between shipping cost and package weight, and generate predictions from a trained Machine Learning model.

Problem Context

The weight of a package is not always the same. It can vary depending on characteristics of the product and the shipping conditions. In this application, we focus specifically on the relationship between the shipping cost and the weight of the package.

The dataset contains historical observations in which each record associates a shipping cost, measured in Colombian Pesos (COP), with the corresponding package weight, measured in kilograms. These observations provide the information required for the Machine Learning model to learn the existing relationship between both variables.

Purpose of the application: The purpose of applying Simple Linear Regression is to use the historical data to learn a linear relationship between shipping cost and package weight. Once trained, the model can estimate the expected weight for a new shipping cost.

Variables Used in the Model

Simple Linear Regression works with two quantitative variables. The independent variable is used as the input, while the dependent variable represents the numerical outcome that the model attempts to predict.

X: Shipping Cost

Represents the cost of shipping used as the input for the prediction. Higher costs generally correspond to heavier packages.

Y: Package Weight

Represents the weight of the package. This is the value that the trained model attempts to estimate.

Dataset

The dataset contains historical observations used by the application to train the Simple Linear Regression model. Each row establishes a relationship between a shipping cost and its corresponding package weight.
