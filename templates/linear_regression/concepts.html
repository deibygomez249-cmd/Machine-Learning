Linear Regression — Concepts

Linear Regression is a supervised learning algorithm that models the linear relationship between one or more independent variables and a continuous target variable.

Simple Linear Regression Equation
y = b0 + b1 * x
  • y: dependent variable (target)
  • x: independent variable (feature)
  • b0: intercept
  • b1: slope
Key Concepts
  • Continuous target: The output is a real number.
  • Least Squares: The model minimizes the sum of squared residuals.
  • R² Score: Measures how well the model fits the data (0 to 1).
  • RMSE: Root Mean Squared Error — the average prediction error.
