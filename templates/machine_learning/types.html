Supervised Learning

The algorithm learns from labeled data, where the expected output is already known.

Used for: Classification and Regression.

Example: Predicting if a student passes based on study hours.

Unsupervised Learning

The algorithm finds patterns in unlabeled data without predetermined outcomes.

Used for: Clustering and Dimensionality Reduction.

Example: Grouping customers with similar purchasing behavior.

Semi-supervised Learning

Combines a small amount of labeled data with a large amount of unlabeled data.

Used for: Problems where labeling is expensive.

Example: Classifying thousands of images when only a few are labeled.

Reinforcement Learning

An agent learns through trial and error, receiving rewards for correct actions and penalties for wrong ones.

Used for: Decision-making over time.

Example: Training an AI agent to play a video game.
