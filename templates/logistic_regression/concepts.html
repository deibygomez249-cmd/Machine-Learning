Logistic Regression — Concepts

Logistic Regression is a supervised learning algorithm used for classification. Despite its name, it is not a regression algorithm — it predicts the probability that an observation belongs to a class.

Why is it a classification algorithm?

It outputs a probability between 0 and 1, which is then mapped to a class using a classification threshold (commonly 0.5).

Binary Classification

Binary classification means the target has exactly two classes. In this project:

  • 0 = Did Not Pass
  • 1 = Passed
Key Terms
  • Independent variable: The input feature (Study Hours).
  • Dependent / target variable: The class to predict (Passed Exam).
  • Classes or labels: The possible values of the target (0 or 1).
  • Probability: The model's estimate of belonging to class 1.
  • Classification threshold: The cutoff used to convert probability to a class (default 0.5).
Linear Regression vs Logistic Regression
  • Linear Regression predicts a continuous value (e.g., weight in kg).
  • Logistic Regression predicts a class (e.g., Passed / Did Not Pass).
