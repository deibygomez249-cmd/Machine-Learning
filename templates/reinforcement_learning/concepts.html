Reinforcement Learning - Concepts

Reinforcement Learning (RL) is a Machine Learning paradigm where an agent learns to make decisions by interacting with an environment. The agent receives rewards or penalties for its actions and progressively learns a policy that maximizes the expected return.

Context of our implementation: a virtual agent navigates a 10×10 grid from the start cell (A) to the target cell (T), avoiding walls (#), minimizing danger zones (D) and learning an optimal path through trial and error.

Concepts applied to our exercise

What is Reinforcement Learning? A learning paradigm where an agent learns by interacting with an environment. Unlike supervised learning, there are no labeled examples. The agent learns from the consequences of its own actions.

Agent: the learner and decision-maker. In our project, it is the virtual robot that moves cell by cell. Its only tools are the four possible actions and the feedback it receives.

Environment: everything the agent interacts with. Our environment is a 10×10 grid of 100 cells that contains 1 start, 1 target, 20 walls, 10 danger zones and 68 free path cells.

State: the current situation of the agent. In our project, a state is the pair (row, column) of the cell where the agent is standing. There are 100 possible states, but only the non-wall ones are reachable.

Action: a decision made by the agent. We use four actions: UP, DOWN, LEFT, RIGHT. Each action moves the agent one cell in that direction if the move is valid.

Reward: positive feedback after a good action. In our grid, only reaching the target (T) produces a reward of +100.

Penalty: negative feedback after a bad or non-productive action. In our grid we have four penalties: -1 for a normal step, -3 for trying to leave the grid, -5 for hitting a wall, -10 for entering a danger zone.

Policy: the agent's strategy. It maps each state to the action the agent decides to take. Our policy is implicit in the Q-values: at each state the agent chooses the action with the highest estimated Q-value.

Step: a single interaction (state, action, reward, next state). Our grid allows up to 200 steps per episode to prevent infinite loops.

Episode: a complete run from start to termination. An episode ends when the agent reaches the target or when the maximum number of steps is reached. We train for 1000 episodes.

Experience: a transition observed by the agent, stored as (state, action, reward, next state). Each experience is used to update the Q-values via the SGDRegressor.

Exploration: trying random actions to discover new parts of the environment. Essential at the beginning of training when the agent knows nothing.

Exploitation: using the knowledge already acquired to choose the action with the best estimated Q-value. Essential at the end of training when the agent has learned a good policy.

Epsilon-Greedy strategy: a simple rule that balances both behaviors. With probability epsilon, the agent explores (random action). With probability (1 − epsilon), the agent exploits (best action).

In our implementation, epsilon starts at 1.0 (100% exploration) and decreases by a factor of 0.995 after each episode until it reaches the minimum of 0.05 (5% residual exploration).

Immediate reward: the feedback received right after a single action. Example: after moving to a normal cell, the reward is -1.

Return: the total discounted reward accumulated from a given state until the end of the episode. The agent's objective is to maximize the expected return.

Discount factor (γ): a number between 0 and 1 that determines how much the agent values future rewards compared to immediate ones. We use γ = 0.95, meaning the agent cares strongly about future outcomes but still prefers rewards that come sooner.

State value V(s): the expected return when starting at state s and following the current policy. It measures how "good" it is to be in a state.

Action value Q(s,a): the expected return when starting at state s, taking action a and following the current policy afterward. This is the value the agent actually learns.

Q-Learning: an off-policy algorithm that updates Q-values using the Bellman equation: Q(s,a) ← r + γ · max Q(s', a'). In our implementation, the Q-values are estimated by an SGDRegressor trained incrementally with partial_fit.

Learning flow in our implementation

Environment Initial State Action Selection Exploration / Exploitation Environment Interaction Reward Next State Q-value Update Next Action Goal / End of Episode
Note: unlike supervised learning, RL does not use labeled examples. The only source of learning is the reward signal received after each action. This makes RL suitable for decision problems where the correct action is not known in advance.
